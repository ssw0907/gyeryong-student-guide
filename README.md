# 계룡 초·중학생 혜택·행사 안내

충남 계룡시에 사는 초·중학생과 학부모가 **충남·계룡의 혜택·프로그램·장학금**과 **대전 행사**를 한곳에서 찾는 정적 웹사이트입니다. 서버 없이 HTML·CSS·JavaScript만으로 동작합니다.

## 폴더 구조

```
index.html           페이지 뼈대
css/style.css        디자인 (모바일 우선)
js/app.js            데이터 읽기·검증·필터·정렬·화면 그리기
data/benefits.json   ★ 충남·계룡 혜택/프로그램/장학금
data/events.json     ★ 대전 행사
data/notices.json    자동 수집한 최신 공고 (직접 고치지 않음)
data/auto-*.json     자동으로 만든 혜택·행사 카드 (직접 고치지 않음)
scripts/             자동 수집 프로그램
.github/workflows/   매일 수집을 실행하는 설정
.nojekyll            GitHub Pages 설정용 빈 파일 (지우지 마세요)
```

사이트에 보이는 내용은 모두 `data/`의 파일에서 나옵니다. 내용만 고칠 때는 `benefits.json`과 `events.json`만 고칩니다.

## 내 컴퓨터에서 미리 보기

`index.html`을 더블클릭하면 데이터를 읽지 못합니다. 이 폴더에서 아래를 실행하고 http://localhost:8000 을 엽니다.

```
python -m http.server 8000
```

## 공통 규칙

- 공식 출처에서 확인한 내용만 넣습니다. 확인 못 한 금액·날짜·조건은 추측하지 말고 `"확인 필요"`로 적습니다.
- 날짜는 반드시 `2027-03-01` 형식이고, 모르면 빈 값 `""`입니다.
- 내용을 확인할 때마다 `checkedAt`을 그 날짜로 바꿉니다.
- 모집 상태는 적지 않습니다. 사이트가 오늘 날짜(한국 시간)로 계산합니다.
- `grades`는 `"초1"`~`"중3"` 중 해당 학년을 모두 적습니다. 학년을 모르면 `[]`로 두면 "학년 확인 필요"로 표시되고, 어떤 학년을 골라도 보입니다.
- 값이 잘못된 항목은 화면에서 빠지고, 페이지 아래에 어떤 항목이 왜 빠졌는지 안내가 나옵니다.
- 쉼표와 따옴표를 조심하세요. 마지막 항목 뒤에는 쉼표가 없고, 따옴표는 영문 큰따옴표 `"`만 씁니다.

저장해 `main`에 푸시하면 1~2분 뒤 사이트에 반영됩니다.

## 혜택·프로그램·장학금 추가·수정

`data/benefits.json`의 `"benefits": [ ... ]`에 항목을 넣습니다.

```json
{
  "id": "gr-101",
  "name": "프로그램 이름",
  "type": "프로그램",
  "field": "과학",
  "target": "초3~6, 계룡시 거주",
  "grades": ["초3", "초4", "초5", "초6"],
  "content": "운영 내용 또는 지원 금액",
  "schedule": "2027.3.6~3.27 토요일",
  "place": "확인 필요",
  "applyMethod": "누리집 신청",
  "applyStart": "2027-02-15",
  "applyEnd": "2027-02-28",
  "applyNote": "",
  "cost": "무료",
  "org": "운영 기관",
  "scope": "계룡시",
  "applyUnit": "개인",
  "url": "https://공식-공고-주소",
  "source": "운영 기관",
  "checkedAt": "2027-02-10",
  "dataYear": "2027",
  "stale": false
}
```

| 항목 | 쓰는 법 |
|---|---|
| `id` | 겹치지 않는 이름 |
| `type` | `혜택`, `프로그램`, `장학금` 중 하나 |
| `field` | 분야. 기존 값과 같은 말을 쓰면 필터에서 함께 묶입니다 |
| `scope` | `전국`, `충남 전체`, `계룡시` 중 하나 |
| `applyStart`, `applyEnd` | 실제 신청 기간. 운영 기간을 대신 넣지 않습니다 |
| `applyNote` | 날짜로 표현 못 하는 안내. 예: `매년 3월 모집`, `상시`, `센터 문의` |
| `applyClosed` | (선택) 정확한 마감일은 모르지만 마감이 확인되면 `true` |
| `applyUnit` | `개인`, `학교 단위`, `학교 추천`, `동아리·모임`, `확인 필요`. 개인·확인 필요가 아니면 카드에 표시됩니다 |
| `dataYear` | 자료의 기준 연도 |
| `stale` | 자료가 작년 이전이면 `true`. 카드에 "오래된 자료"로 표시됩니다 |

**상태 표시:** 프로그램·장학금만 "모집 중 / 예정 / 마감"이 붙습니다. 신청 날짜가 없고 `applyClosed`도 없으면 "일정 확인"이 됩니다. 마감 7일 이내는 강조됩니다. 마감된 항목은 "마감된 항목 보기"를 켜야 보입니다.

**수록 범위**
- 넣는 것: 충남 전체 초·중학생 대상, 계룡시 초·중학생 대상. 도 단위 기관이 충남 전체 학생에게 운영하면 기관 소재지와 관계없이 넣습니다.
- 빼는 것: 다른 시·군만의 사업, 3자녀 이상·한부모·저소득이 자격 요건인 것(장학금 포함), 고등학생 전용·성인 전용, 재학생이 아닌 학교 밖 청소년 전용.
- 학교가 신청하는 항목은 빼지 않고 `applyUnit`을 `학교 단위`로 적습니다.
- 논산계룡교육지원청 항목은 범위를 `계룡시`로 두고 내용에 논산·계룡 관내임을 적습니다.

## 대전 행사 추가·수정

`data/events.json`의 `"events": [ ... ]`에 항목을 넣습니다.

```json
{
  "id": "ev-101",
  "name": "행사 이름",
  "field": "과학",
  "target": "초4~6",
  "grades": ["초4", "초5", "초6"],
  "targetUnconfirmed": false,
  "eventStart": "2027-05-01",
  "eventEnd": "2027-05-02",
  "schedule": "10:00~16:00",
  "place": "국립중앙과학관",
  "applyMethod": "누리집 예약",
  "applyStart": "2027-04-10",
  "applyEnd": "2027-04-25",
  "applyNote": "",
  "cost": "무료",
  "capacity": "30명, 선착순",
  "org": "주최 기관",
  "url": "https://공식-공고-주소",
  "source": "주최 기관",
  "checkedAt": "2027-04-01",
  "residency": "제한 문구 없음(계룡 학생 참여 명시 없음, 신청 전 확인)"
}
```

| 항목 | 쓰는 법 |
|---|---|
| `field` | `과학`, `문학`, `기타` 중 하나 |
| `targetUnconfirmed` | 초·중학생 참여 여부를 확인 못 했으면 `true`. 카드에 "대상 확인 필요"로 표시됩니다 |
| `eventStart`, `eventEnd` | 행사 기간. 둘 다 비우면 "상시"로 표시됩니다 |
| `cost` | `무료`, `유료 3,000원`, `확인 필요` 등. `무료`라는 말이 있으면 "무료만 보기"에 나옵니다 |
| `residency` | 거주지 조건. `대전 거주자 한정`처럼 `한정`이 들어가면 카드에 눈에 띄게 표시됩니다 |

**상태 표시:** 오늘 날짜로 "신청 중 / 예정 / 지난 행사"를 계산합니다. 신청이 마감된 행사와 지난 행사는 "신청 마감·지난 행사 보기"를 켜야 보입니다. 신청 마감 7일 이내는 강조됩니다. 정기 행사는 지난 일정을 그대로 두고 `applyNote`에 `매년 12월 모집`처럼 적습니다.

**수록 범위:** 대전에서 열리고 초·중학생이 참여할 수 있는 행사만 넣습니다. 지원금·급여 같은 제도와 고등학생·성인 전용은 뺍니다. 대전 관내 학교·학생으로 제한된 행사는 뺐으며, 넣을 때는 `대전 거주자 한정`으로 표시합니다.

## 최신 공고 자동 수집

GitHub Actions가 매일 오전 6시(한국 시간)쯤 `scripts/collect_notices.py`를 실행해 `data/notices.json`을 갱신합니다. 사람의 확인 없이 바로 사이트에 반영됩니다.

공고는 따로 탭이 없고, 충남·계룡 공고는 혜택 탭에, 대전 공고는 대전 행사 탭에 "공고" 카드로 섞여 나옵니다. 모집 중·예정 항목 다음에 최신 공고 순으로 보이고, 30일이 지난 공고는 "마감된 항목·지난 공고 보기"를 켜야 보입니다. 제목에 학년(`초3~6`, `중학생` 등)이 있으면 학년 필터에 쓰고, 이미 카드로 있는 프로그램과 제목이 같은 공고는 숨깁니다. 수동 실행은 저장소 **Actions → 최신 공고·프로그램 자동 수집 → Run workflow**입니다.

- 제목, 기관, 날짜, 링크만 모읍니다. 금액이나 자격 조건은 공식 링크에서 확인합니다.
- 누락을 줄이는 것이 우선입니다. 교육·청소년 기관은 `EXCLUDE`(학생과 무관한 것이 확실한 단어)만 적용하고, 일반 행정·연구 기관은 제목에 `INCLUDE`(학생 관련 단어)도 있어야 합니다. 그래서 관련 없는 공고나 다른 시·군 공고도 섞일 수 있습니다.
- 기관을 추가하려면 `SOURCES`에 게시판을 넣습니다. 게시판 형식이 새로우면 읽는 함수도 필요합니다.
- 최근 180일 공고만 남기고, 최대 500건까지 보관합니다.
- 사이트의 `robots.txt`가 허용하는 게시판만 읽습니다. 허용하지 않거나 읽지 못한 기관은 해당 탭의 목록 아래에 바로가기 링크로 표시합니다. 게시판 구조가 바뀐 기관도 여기에 나타납니다.

**자동 수집이 안 되는 기관 (2026-11-09 확인)**

`data/notices.json`의 `sources`에서 `"ok": false`인 기관입니다. `robots.txt`가 수집을 허용하지 않는 아래 기관은 매일 실패로 기록되는 것이 정상이고, 사이트에는 바로가기 링크로 나옵니다.

- 충남·계룡: 계룡시청, 충청남도교육청, 충청남도교육청과학교육원, 안전수련원, 해양수련원, 충무교육원, 충남평생교육진흥원
- 대전: 대전광역시(OK예약·도서관·미술관), 대전광역시교육청, 대전교육과학연구원, 대전 공공도서관

논산계룡교육지원청은 수집이 허용되지만 GitHub 서버에서 접속 시간 초과가 나는 날이 있습니다. 그런 날은 바로가기로 나오고, 이전에 모은 공고는 180일 동안 남습니다.

## 혜택·행사 카드 자동 수집

같은 작업에서 `scripts/collect_programs.py`도 실행합니다. 대상·기간·비용이 **표 칸으로 나뉜 프로그램 목록**만 읽어 카드로 만들고, 카드에 "자동 수집" 표시가 붙습니다. AI를 쓰지 않으므로 요금이 들지 않습니다.

| 기관 | 저장 파일 | 넣는 것 |
|---|---|---|
| 계룡시청소년별마루센터 | `data/auto-benefits.json` | 최근 프로그램 12건 중 신청이 안 끝난 것 |
| 충남평생교육 강좌 신청(cnall.or.kr) | `data/auto-benefits.json` | 초등·중학생 대상 강좌 중 남부·서부평생교육원, 평생교육원, 학생교육문화원 것. 다른 시·군 도서관 강좌는 뺌 |
| 국립중앙과학관 | `data/auto-events.json` | 아직 끝나지 않은 교육 프로그램 |
| 정부 공공서비스(혜택) 정보 API | `data/auto-benefits.json` | 계룡시·충남교육청 혜택 전부, 충청남도·중앙행정기관 혜택 중 제목에 학생 관련 단어가 있는 것 |

- `benefits.json`, `events.json`에 손으로 넣은 항목과 이름·날짜가 같으면 자동 카드는 만들지 않습니다. 손으로 정리한 내용이 우선입니다.
- 학년을 확실히 읽지 못하면 "학년 확인 필요", 비용·정원을 모르면 "확인 필요"로 나옵니다.
- 한 기관을 읽지 못한 날은 그 기관의 지난 결과를 그대로 둡니다.
- 일반 게시판 글(본문·첨부 PDF·포스터 이미지)은 학년·날짜를 정확히 뽑을 수 없어 자동 카드로 만들지 않습니다. 이런 공고는 "공고" 카드(제목과 링크)로 나옵니다.
- 대전 OK예약, 대전 공공도서관은 `robots.txt`가 수집을 허용하지 않아 넣지 않았습니다.
- 정부 혜택 API는 [공공데이터포털](https://www.data.go.kr/data/15113968/openapi.do) 인증키가 필요합니다. 저장소 **Settings → Secrets and variables → Actions**의 `DATA_GO_KR_KEY`에 저장되어 있습니다. 키가 없거나 호출이 실패한 날은 지난 결과를 그대로 둡니다.
- 다른 시·군과 대전의 혜택은 대부분 그 지역 주민만 받을 수 있어 넣지 않습니다. 범위는 `collect_programs.py`의 `gov24_wanted`에서 바꿉니다.
- 농업, 노인, 청년·대학생, 유아, 시설·사업자 대상처럼 초·중학생과 학부모에게 무관한 혜택은 뺍니다. 기준은 `GOV24_UNRELATED_NAME`, `GOV24_UNRELATED_TARGET`, `GOV24_UNRELATED_FIELD`에서 바꿉니다.
- 한부모, 입양, 저소득이 조건인 혜택도 뺍니다. 다자녀 가정이나 희망자도 받을 수 있는 혜택은 남깁니다. 기준은 `GOV24_CONDITION_NAME`, `GOV24_CONDITION_TARGET`, `GOV24_OPEN_TO_ALL`에서 바꿉니다.

## GitHub Pages로 배포하기

1. GitHub에 저장소를 만들고 이 폴더를 올립니다.
2. 저장소 **Settings → Pages**에서 Source를 "Deploy from a branch", Branch를 `main`, 폴더를 `/ (root)`로 고르고 저장합니다.
3. 잠시 뒤 `https://<사용자이름>.github.io/<저장소이름>/`에서 열립니다.
